# Car Showroom Management System

Система управления автосалоном на **PHP + MySQL**: каталог автомобилей по компаниям, поиск, приём заявок от клиентов. Интерфейс переведён на **русский язык**.

## Возможности

- Публичный каталог автомобилей с поиском и фильтрацией по компаниям
- Страница компании и детальная карточка автомобиля
- Форма обратной связи / заявок (enquiry)
- Админ-панель: управление компаниями и автомобилями, слайдер на главной, обработка заявок, статичные страницы

## Технологии

- PHP, MySQL (mysqli)
- HTML, CSS, Bootstrap

## Установка (XAMPP)

1. Скопируйте папку проекта в `C:\xampp\htdocs\`.
2. Запустите **Apache** и **MySQL** в XAMPP Control Panel.
3. Создайте базу данных `csmsdb` и импортируйте дамп `csmsdb.sql` через phpMyAdmin.
4. Проверьте параметры подключения в `includes/dbconnection.php`.
5. Откройте в браузере: `http://localhost/<папка_проекта>/`

### Вход в админ-панель

```
Username: admin
```

> ⚠️ Пароль администратора хранится в БД в виде хеша (таблица `tbladmin`). После установки войдите через восстановление пароля или задайте новый хеш вручную.
